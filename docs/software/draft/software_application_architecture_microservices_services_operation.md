# 運用＠マイクロサービスアーキテクチャ

## セキュリティ運用

### マルウェア対策

<table>
  <thead>
    <tr>
      <th>運用設計項目</th>
      <th>中央集中型の例</th>
      <th>分散型の例</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>コンテナイメージの OS・言語・ライブラリ・依存パッケージ更新</td>
      <td>すべてのマイクロサービスで OS や言語、依存ライブラリのバージョンを統一し、月次または四半期ごとに更新する</td>
      <td>各マイクロサービスが自律的にライブラリを更新し、脆弱性を都度修正する</td>
    </tr>
    <tr>
      <td>脆弱性スキャン運用</td>
      <td>すべてのマイクロサービスで CI/CD にスキャンを統合し、結果を中央で集約して分析する</td>
      <td>各マイクロサービスが自律的にスキャンを実施し、修正対応を行う</td>
    </tr>
    <tr>
      <td>マルウェア検知運用</td>
      <td>すべてのマイクロサービスの通信とファイルをセキュリティ基盤で自動スキャンし、結果を中央で管理する</td>
      <td>各マイクロサービスが自律的にログを分析し、異常を検知する</td>
    </tr>
    <tr>
      <td>マルウェア定義更新</td>
      <td>すべてのマイクロサービスで使用する検知ルールやシグネチャを統一し、セキュリティチームが一括更新する</td>
      <td>各マイクロサービスが自律的に独自定義を必要に応じて更新する</td>
    </tr>
  </tbody>
</table>

### アプリケーションデータの暗号化

<table>
  <thead>
    <tr>
      <th>運用設計項目</th>
      <th>中央集中型の例</th>
      <th>分散型の例</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>証明書ローテーション</td>
      <td>Istio の場合、ワークロード証明書の有効期限を統一し、既定では 24 時間が経過する前に自動更新する</td>
      <td>各マイクロサービスが自律的に有効期限前に手動で更新する</td>
    </tr>
    <tr>
      <td>鍵・トークンローテーション</td>
      <td>すべてのマイクロサービスで Vault や Secret Manager を利用し、自動ローテーションを統一運用する</td>
      <td>各マイクロサービスが自律的に Secret を管理し、手動で更新する</td>
    </tr>
    <tr>
      <td>通信経路暗号化</td>
      <td>すべてのマイクロサービス間通信を TLS で統一し、Istio や Ingress Gateway で中央管理する</td>
      <td>各マイクロサービスが自律的に TLS を設定し、証明書を管理する</td>
    </tr>
    <tr>
      <td>一時ファイル暗号化</td>
      <td>すべてのマイクロサービスで暗号化ルールを統一し、共通ボリュームを保護する</td>
      <td>各マイクロサービスが自律的にアプリケーション側で暗号化実装を管理する</td>
    </tr>
    <tr>
      <td>暗号化ログ監査</td>
      <td>すべてのマイクロサービスで暗号化通信ログを中央に収集し、定期的に検証する</td>
      <td>各マイクロサービスが自律的にログを監査し、改善を進める</td>
    </tr>
  </tbody>
</table>

    </tr>
    <tr>
      <td>鍵ローテーション</td>
      <td>すべてのマイクロサービスで鍵ローテーション周期を統一し、KMS や HSM で自動ローテーションを実施する</td>
      <td>各マイクロサービスが自律的にスケジュールを定めて鍵をローテーションする</td>
    </tr>
    <tr>
      <td>暗号化状態の監査</td>
      <td>すべてのマイクロサービスでストレージの暗号化状態を定期的にチェックし、レポートを中央で集約する</td>
      <td>各マイクロサービスが自律的に暗号化設定を点検する</td>
    </tr>
    <tr>
      <td>バックアップデータ暗号化</td>
      <td>すべてのマイクロサービスでバックアップデータの暗号化方式を統一し、暗号化を自動適用する</td>
      <td>各マイクロサービスが自律的にバックアップ処理に暗号化を設定する</td>
    </tr>
  </tbody>

    </tr>
    <tr>
      <td>認可ポリシー管理</td>

    </tr>
    <tr>
      <td>認証ログ監査</td>
      <td>すべてのマイクロサービスで認証ログを中央監査基盤に集約し、異常を検知する</td>
