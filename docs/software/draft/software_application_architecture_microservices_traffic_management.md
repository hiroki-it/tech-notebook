## 03. アプリケーションデータの暗号化

### アプリケーションデータの暗号化

各マイクロサービス間通信では、TLS による暗号化を採用する。

<br>

### 相互 TLS 認証

#### ▼ サイドカーパターン

サイドカーモードの Istio では、各マイクロサービスの istio-proxy 間で相互 TLS 認証し、アプリケーションデータを暗号化／復号する。
