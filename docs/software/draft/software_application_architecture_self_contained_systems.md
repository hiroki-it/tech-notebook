## 自己完結アーキテクチャ

複数の自己完結システム（フロントエンド、バックエンド、データベースのセット）からなるアーキテクチャのこと。

自己完結システム内のバックエンドを複数のマイクロサービスの分割することで、部分的なマイクロサービスアーキテクチャとすることもできる。
