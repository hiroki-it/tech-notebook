## 02. MAC アドレス：Media Access Control address

NIC、有線 LAN、無線 LAN、スマートフォンなどに紐づけられた機器固有の識別子のこと。

機器メーカーコード、機器メーカー管理番号から構成される。

同じ識別子は他に存在しない。
